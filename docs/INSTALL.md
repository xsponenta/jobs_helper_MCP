# Як встановити Jobs Helper

Помічник шукає вакансії на **DOU, Djinni і Happy Monday**, адаптує ваше CV під кожну вакансію і заповнює форму відгуку прямо у вашому браузері. Відправляє так, як ви обрали для кожного сайту. Працює всередині Claude.

---

## Варіант A: Claude Desktop, без технічних знань (≈ 3 хвилини)

1. **Встановіть Claude Desktop**, якщо його ще немає: https://claude.ai/download
2. **Завантажте розширення:** [jobs-helper.mcpb](https://github.com/xsponenta/jobs_helper_MCP/raw/main/release/jobs-helper.mcpb).
3. **Відкрийте завантажений файл** подвійним кліком. Claude Desktop запропонує встановити розширення, натисніть «Install».
   Якщо подвійний клік не спрацював: Claude Desktop → **Settings → Extensions**, і перетягніть файл у вікно.
4. **Заповніть форму розширення:**
   - ім'я, прізвище, email, телефон, місто;
   - посилання на LinkedIn (без нього Djinni не прийме відгук без входу в акаунт);
   - **ваше CV**: файл PDF, DOCX, MD або TXT. Це єдине джерело фактів: помічник нічого не дописує від себе;
   - бажана зарплата в USD, рівень англійської;
   - **як надсилати відгуки** на кожному сайті:
     - `manual`: помічник заповнює форму, «Надіслати» натискаєте ви. Для DOU стоїть саме так, бо правила DOU забороняють автоматичні відгуки;
     - `confirm`: помічник заповнює і показує вікно «Надіслати / Скасувати»;
     - `auto`: надсилає сам.
5. **Увімкніть розширення** перемикачем і відкрийте новий чат.

Перший запуск може тривати 1–2 хвилини: Claude Desktop завантажує потрібні компоненти, а при першому відгуку — ще й браузер.

### Як користуватися
Напишіть у чаті, наприклад:
- «Знайди remote Python-вакансії під моє CV і відгукнись на одну найкращу»
- «Підбери 3 вакансії React, але поки не відгукуйся, я подивлюсь»
- «Напиши LinkedIn-пост, що я шукаю роботу, і підготуй оновлення профілю»

Що відбуватиметься:
- **Під час відгуку відкриється вікно браузера** із заповненою формою. Залежно від налаштування ви натискаєте «Надіслати» самі або підтверджуєте у вікні.
- **Якщо сайт попросить увійти,** відкриється сторінка входу. Увійдіть, і відгук продовжиться автоматично. Пароль бачите тільки ви. Сесія зберігається у вашій папці `~/.jobs_helper`.
- **Якщо у формі є питання, відповіді на яке немає у вашому CV** (згода на обробку даних, віза, нестандартні питання), помічник спитає вас і нічого не вигадає.
- **LinkedIn-пост:** відкриється вікно LinkedIn з готовим текстом, публікуєте ви.

Усі ваші дані (профіль, сесії, історія відгуків) лежать лише на вашому комп'ютері в папці `~/.jobs_helper`.

## Варіант B: Claude Code / термінал (для розробників)

Потрібен [uv](https://docs.astral.sh/uv/getting-started/installation/). Клонувати репозиторій не треба.

```bash
# 1. профіль, CV і браузер (один раз)
uvx --from git+https://github.com/xsponenta/jobs_helper_MCP jobs-helper init --cv ~/Documents/CV.pdf
#    далі відредагуйте ~/.jobs_helper/candidate.yaml (ім'я, email, телефон, LinkedIn)

# 2. підключити до Claude Code
claude mcp add jobs-helper -s user -e JOBS_APPLY_BACKEND=browser -- \
  uvx --from git+https://github.com/xsponenta/jobs_helper_MCP jobs-helper-mcp

# 3. перевірка
uvx --from git+https://github.com/xsponenta/jobs_helper_MCP jobs-helper status
```

**Claude Desktop без розширення:** додайте в `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "jobs-helper": {
      "command": "uvx",
      "args": ["--from", "git+https://github.com/xsponenta/jobs_helper_MCP", "jobs-helper-mcp"],
      "env": {"JOBS_APPLY_BACKEND": "browser"}
    }
  }
}
```

**Корисні команди:**
```bash
jobs-helper policy set djinni auto      # змінити спосіб відправки
jobs-helper login dou                   # увійти заздалегідь (інакше вхід відкриється сам)
jobs-helper login linkedin              # необов'язково: публікація через API (див. README)
```
(через `uvx --from git+https://github.com/xsponenta/jobs_helper_MCP` перед кожною командою)

## Якщо щось не працює
- **Claude не бачить інструментів:** перевірте, що розширення увімкнене, і відкрийте новий чат.
- **«candidate_profile_missing»:** заповніть форму розширення або `~/.jobs_helper/candidate.yaml`.
- **Форма заповнилась неправильно:** не надсилайте її, закрийте вікно. Помічник нічого не відправляє без вашої політики.
- **Діагностика:** `jobs-helper status` показує, що налаштовано, а що ні.
